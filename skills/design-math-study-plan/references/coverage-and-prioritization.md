# 资料覆盖、优先级与习题取舍

## 目录

1. 知识点覆盖
2. 来源角色
3. 优先级评分
4. 重叠和替代
5. 习题四级分类
6. 压缩时间时的删减顺序

## 1. 知识点覆盖

覆盖矩阵追踪：

- 主要概念；
- 命名定理；
- 后续依赖的引理；
- 关键证明方法；
- 主线例子；
- 研究应用；
- 正文依赖的习题结论。

不追踪决定不迁移的每一道重复习题或历史旁支。

## 2. 来源角色

为每份来源选择主要角色：

- **基础骨架：** 建立共同语言和主线工具；
- **专题论文：** 展示方法在具体问题中的使用；
- **辅助讲义：** 补动机、证明细节或题解；
- **替代读物：** 以更易读方式覆盖难来源的入门部分；
- **长期入口：** 当前只学对象、主结论和证明机制；
- **查阅手册：** 不顺序阅读。

一个来源可以有次要角色，但必须有一个主定位。

## 3. 优先级评分

从下列维度判断，不必机械求和：

- 对目标研究方向的相关性；
- 后续依赖度；
- 当前可读性；
- 时间收益；
- 是否有替代资料；
- 是否包含独特方法；
- 导师明确优先级。

给出高、中、低或主线、次线、长期入口，并解释理由。

## 4. 重叠和替代

若两份资料覆盖同一主题：

1. 选叙述最完整且最符合读者基础者为主；
2. 从另一份只抽取更好的动机、例子、证明或练习；
3. 对不同符号和假设建立对照；
4. 计划中明确何时不再回查被替代来源。

已有重制版和辅助材料时，更新阅读入口；不要让旧计划继续指向影印件或不完整草稿。

## 5. 习题四级分类

- **M：主线结论。** 后文依赖者进入正文。
- **C：核心训练。** 必做，检验关键概念或方法。
- **H：第二遍/挑战。** 只保留含不可替代方法者。
- **D：推迟或删除。** 重复、过长、偏门、分类计算或低收益。

先用已有导读、课程目标和后文依赖建立白名单，再补真正缺失的方法题。不要把原书题数当作必须迁移的配额。

## 6. 压缩时间时的删减顺序

时间不足时依次：

1. 删除重复练习；
2. 删除历史旁支和同质例子；
3. 把低优先级专题降为概览；
4. 把长期入口只保留词典、主定理和阅读地图；
5. 降低深层输入的证明复现要求；
6. 最后才考虑删主线结果。

不可删除后文实际调用的定义或引理。任何删减都同步更新依赖图、周计划和验收。
