## 1. 三类证明责任

### 1.1 完整证明

逐步证明主线结果，不省略会改变结论成立性的环节。至少显式处理：

- 所有量词、取值范围和推理顺序；
- 需要统一处理的对象、参数和例外情形；
- 记号、运算顺序、对象关系和归一化约定；
- 定义、构造和结论之间的对应关系；
- 对象性质、映射条件、有限性和边界情形；
- 关键计算、常数依赖和结论适用范围；
- 所调用引理的全部假设。

### 1.2 模型证明

完整证明一个代表性情形，再精确说明一般情形需要哪些新增工具。适合：

- 一般定理的核心机制已在一个代表性特例中完全显现；
- 一般化主要增加技术分类或标准结构理论；
- 本书主线只实际使用模型情形。

不要从模型证明直接宣称一般定理“同理”。列出推广中新增的定义、构造、分类或适用条件方面的障碍。

### 1.3 只陈述和使用的结果

本书不展开证明的非平凡结果加星号，并明确说明是否只需了解结论、需精确理解并会调用，或需看证明路线。实际调用的结果写清作者、名称、精确假设与结论、使用部分、未证明边界和来源。先解释整体含义和准确直觉；证明路线只有确实帮助理解时才给，标明它不是完整证明，不强制另列关键引理和技术清单。不得在可见正文用“深层输入、结构输入、标准输入”标记证明责任。

证明提要不能冒充完整证明，模型证明不能冒充一般证明。发现稿件未履行已批准的证明责任时，记录缺口并补足，或报告后取得范围变更授权，不能自行降级。因事实错误必须收紧陈述时，也须报告证据及其对后续学习的影响。

## 2. 非平凡证明的统一格式

### 2.1 何时必须分步

满足任一条件即分步：

- 证明超过几句，有两个以上逻辑阶段 / 数学动作 / 待处理数学对象；
- 包含充分性与必要性 / 包含多个 case；
- 结论本身不易理解。

只有证明自然、几句话内完成、且命题一眼可懂时才可不分步。一个编号若接连承担构造、存在性、有限性、估计和归约等，均需检查是否拆开以降低推理密度。

### 2.2 粗阶段与细步骤

对双向证明或多情形证明，先用统一粗阶段标题，例如：

```latex
\proofphase{第一阶段：证明必要性}
\begin{enumerate}
  \item ...
\end{enumerate}

\proofphase{第二阶段：证明充分性}
\begin{enumerate}
  \item ...
\end{enumerate}
```

短而自然的动作直接叙述；确需标题时用读细节前便能理解的具体加粗短语（标题必须读细节前即可理解，读细节后也能用于回顾，如果「只有已经读完细节了再回来才能看懂标题是什么意思」则视为不合格标题），必要时接楷体图景，再展开正体论证。长证明及多方向、多情形证明用统一粗体阶段组织短步骤，说明情形如何覆盖目标、各段如何回到结论。关键计算、存在性、常数选择和最后闭合不得藏在“同理”中；精确回链也须核对适用条件。

以下两例展示不同的步骤组织方式，均只是编号证明中的局部片段。代码放在已有的enumerate环境中；小字宏采用统一样式。按内容选择写法，不要求每步都配标题或小字。

**示例一：正常字号给出具体动作，小字解释理由。**

语境：多项式理想$J(G)$已经定义，所在多项式环的Noether性已经说明。此处需要找出一个有限次数上界。

```latex
\item 由 Noether 性，$G$ 的定义理想 $J(G)$ 由次数 $\le m$ 的多项式生成。
\stepdetail{多项式环是Noether环，所以$J(G)$有有限个生成元。
\par 取非负整数$m$不小于各非零生成元的次数；没有非零生成元时取$m=0$。
这样即得到所需的统一次数上界。}
```

正常字号已给出动作和结论：把生成方程的次数限制在同一个上界以内。小字解释有限生成如何给出这个上界。读者先能记住本步在干什么，再就近补齐理由；熟悉后，一句正常字号即可唤回这些细节。

**示例二：几个短而可追踪的动作，直接用正常字号展开。**

下面只展示Milnor–Švarc证明中的一段计算。群$\Gamma$等距作用于度量空间$(X,d)$；已有$x_0\in X$、$R>0$、$\gamma\in\Gamma$和
$S=\{s\in\Gamma:d(x_0,sx_0)\le3R\}$。

已选整数$N\ge1$、点$p_0,\ldots,p_N\in X$与群元$\gamma_0,\ldots,\gamma_N\in\Gamma$，满足相邻分点距离至多$R$，且$d(p_i,\gamma_i x_0)\le R$；端点取$\gamma_0=e,\gamma_N=\gamma$，其中$e$是群单位元。目标是把$\gamma$写成$S$中元素的乘积。

进入整个证明时，可以用下面一句说明构造目标：

> 要从群作用中找出有限生成集，我们先收集位移有界的群元，再把一条长测地线切成短段，说明这些群元足以拼出任意 γ ∈ Γ。

进入下面的局部阶段时，则可先给出几何图景：

> 沿最短路径逐段前进，在每个分点附近选一个轨道点；相邻轨道点足够近，便能用 S 中的元素把对应的群元接起来。

二者分别说明整个证明的路线与本阶段怎样推进，不能只因随后有严格计算就一起删去。以下$1\le i\le N$：

```latex
\item 经相邻分点连接轨道点，三段各至多长$R$，故
\[
d(\gamma_{i-1}x_0,\gamma_i x_0)
\le d(\gamma_{i-1}x_0,p_{i-1})+d(p_{i-1},p_i)
   +d(p_i,\gamma_i x_0)\le3R.
\]
\item 要从群元$\gamma_{i-1}$接到$\gamma_i$，在右边乘上
$s_i=\gamma_{i-1}^{-1}\gamma_i$。等距性给出
\[
d(x_0,s_ix_0)=d(\gamma_{i-1}x_0,\gamma_i x_0)\le3R,
\]
所以$s_i\in S$。
\item 依次相乘，中间各项抵消：
\[
s_1\cdots s_N=(\gamma_0^{-1}\gamma_1)\cdots
(\gamma_{N-1}^{-1}\gamma_N)=\gamma.
\]
因此得到由$S$中元素组成的词，且这个词的长度至多为$N$。
```

这三步分别估计相邻轨道点距离、构造连接两个群元的增量、相乘得到目标群元。动作和计算都短，可直接用正常字号，不必再拆成标题加小字。

正常字号首先帮助读者低难度地理解、记住“这一步在干什么”，须有具体动作、构造、关系或结论，不能只充当标题，也不以独立组成完整证明为硬要求。读者未读小字时已应获得有意义的步骤印象。

小字用宋体补足第一遍可能卡住、放在正常字号又会冗长或打断理解的理由与计算，可以包含较多必要细节，不限于边角信息。正常字号与小字共同承担完整证明；不能把全部实质内容退到小字，也不能在正常字号中大段堆积。细节紧邻所解释的步骤；出现新的主要阶段时，在正常字号中明确组织出来。

容易理解和记忆的步骤可以正常字号只写一句，由小字补充分理由；也可以正常字号展开大部分乃至全部论证，少用或不用小字，不规定比例。初读时应顺畅建立印象并找到理由；熟练后应能沿正常字号快速回忆框架、重建细节，遗忘时立即追溯。若简写只适合专家解码，须改成便于初读者理解的动作。

### 2.3 Case 格式

说明各情形覆盖所需范围；若论证依赖互斥，另作说明。再逐案处理。每个 case 明确：

- 触发条件；
- 使用的输入；
- 得到的中间结论；
- 如何回到总目标。

不能只写“其他情形类似”，除非给出精确对称、替换或归约。

## 3. 证明前后的解释

定理后、证明前的注记应无需先读证明即可理解。全文路线和局部阶段图景作用不同，可以同时保留；不能因为严格步骤随后展开同一件事，就把有效引导删作重复。注记标题及内容用楷体，证明正文保持正体；阶段格式见第2节。

### 3.1 证明前

对长证明先给路线图，例如

- 障碍是什么；
- 将构造什么中间对象；
- 哪一步产生核心推进或关键约束；
- 最后如何闭合。

路线图不能预先使用尚未引入的依赖而不加解释；必要时链接第零章。足够自然的短证明不必另加。

### 3.2 证明后

非平凡定理后给结构注记，说明：

- 定理真正说了什么；
- 哪些假设负责哪些结论；
- 证明的核心思想、核心机制、关键技巧、易错点等；
- 哪一步最不可替代；
- 后文如何调用。

若定理已经非常简单且证明完全透明，可以省略独立注记，避免机械增框。

## 4. 常见错误检查

### 4.1 定义与假设

- 是否漏了对象范围、可用结构、存在性、有限性或其他必要条件；
- 等价刻画是否在当前类别内才成立；
- 极端、退化或边界情形是否单独处理；
- 是否把只在附加条件下成立的性质当成一般结论；
- 是否把相近但不同层次的对象混为一谈。

### 4.2 约定与一致性

在全书开头列出约定并逐章复核。例如：

- 记号、运算次序和对象之间的对应关系；
- 等价、映射、归一化和标签的定义；
- 同一符号在不同章节的取值范围；
- 引用结论的前提与当前语境。

不要靠“习惯”判断；按定义、公式和最小例子逐项检验。

### 4.3 条件、映射与极限过程

- 带参数或带例外情形的陈述是否需要统一范围或统一选择；
- 相似性质、不同类型的像、闭包或完成等操作是否混用；
- 不同收敛、极限或归一化的定义是否严格区分；
- 变换、限制、延拓或比较时是否核查全部前提。

### 4.4 证明顺序

- 不得循环调用待证结论；
- 不得先用后证且无回链；
- 不得把未明确允许调用的书外结果暗中塞入当前完整证明；
- 练习中的结论若正文依赖，应提升为正文。

### 4.5 量纲、缩放与参数

- 用缩放检验公式量纲；
- 检查常数依赖是否统一；
- 检查“取足够大”能否同时满足有限或无限多个条件；
- 检查方向、逆向操作、对偶构造和临界参数；
- 检查端点、空指标集和分段公式。

## 5. 星号结果的写法

结果名称按实际类型加星号；下面仅示范定理。先精确陈述，再解释整体含义、用途与阅读要求，并注明未证明边界和来源：

```latex
\begin{theoremstar}[结果名称]\label{thm:...}
在假设……下，有……
\end{theoremstar}

\begin{note}
这个结论说的是……，可以直观地理解为……。
本书后文只使用……。读者需要……。
本书不展开……的证明，所引精确版本及来源为……。
\end{note}
```

证明路线只有确实帮助理解时才另给，并明说不是完整证明；不默认附上编号技术提要。星号本身不能代替自然中文的阅读指导。

## 6. 自洽性的诚实边界

可独立学习不要求把全部现代数学从公理重建。合格的分层自洽至少要求：

- 基本对象和符号在书内定义；
- 主线结论的精确形式在书内陈述；
- 每次调用能追溯到正文、前置章或明确陈述的引用结果；
- 引用结果的作用和未证明边界可理解；
- 读者不必回查被重制的来源才能知道当前论证在做什么。

若用户要求“完全替代原资料”，优先覆盖原资料的主要概念、命名结果和关键证明；仍无法在合理篇幅内展开的专著级基础，必须在写作合同中向用户说明。
