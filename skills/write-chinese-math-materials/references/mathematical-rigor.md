## 1. 三类证明责任

### 1.1 完整证明

逐步证明主线结果，不省略会改变结论成立性的环节。至少显式处理：

- 所有量词、取值范围和推理顺序；
- 需要统一处理的对象、参数和例外情形；
- 记号、运算顺序、对象关系和归一化约定；
- 定义、构造和结论之间的对应关系；
- 对象性质、映射条件、有限性和边界情形；
- 关键计算、常数依赖和结论适用范围；
- 所调用引理的全部假设。

### 1.2 模型证明

完整证明一个代表性情形，再精确说明一般情形需要哪些新增工具。适合：

- 一般定理的核心机制已在一个代表性特例中完全显现；
- 一般化主要增加技术分类或标准结构理论；
- 本书主线只实际使用模型情形。

不要从模型证明直接宣称一般定理“同理”。列出推广中新增的定义、构造、分类或适用条件方面的障碍。

### 1.3 深层输入

将专著级或跨领域输入标成带星号结果。必须给出：

1. 精确假设；
2. 精确结论；
3. 正文实际使用的输出；
4. 关键引理和证明架构；
5. 未展开的技术；
6. 第一遍阅读要求；
7. 原始来源。

几页证明地图不能标为“完整证明”。若发现现有稿件只有架构，应降低证明等级，而不是用概括性文字填充篇幅。

## 2. 非平凡证明的统一格式

### 2.1 何时必须分步

满足任一条件即分步：

- 证明超过几句并有两个以上逻辑阶段；
- 包含充分性与必要性；
- 包含多个 case；
- 需要构造对象后再验证性质；
- 需要统一处理多个对象、参数或适用范围；
- 结论本身不易理解。

只有证明自然、几句话内完成、且命题一眼可懂时才可不分步。

### 2.2 粗阶段与细步骤

对双向证明或多情形证明，先用统一粗阶段标题，例如：

```latex
\proofphase{第一阶段：证明必要性}
\begin{enumerate}
  \item ...
\end{enumerate}

\proofphase{第二阶段：证明充分性}
\begin{enumerate}
  \item ...
\end{enumerate}
```

粗阶段标题全书统一使用粗体宏；不要有的加粗、有的不用同一层级。

单一主线证明直接用：

```latex
\begin{proof}
\leavevmode
\begin{enumerate}
  \item 写出本步的数学动作。

  \stepdetail{补充真正需要的理由、计算、量词或直观。}
  \item ...
\end{enumerate}
\end{proof}
```

局部解释使用较小字号宋体，但不要把所有证明正文都塞进 `\stepdetail`。主逻辑留在正常字号，解释补足不显然处。

### 2.3 Case 格式

先说明 cases 穷尽且互斥，再逐案处理。每个 case 明确：

- 触发条件；
- 使用的输入；
- 得到的中间结论；
- 如何回到总目标。

不能只写“其他情形类似”，除非给出精确对称、替换或归约。

## 3. 证明前后的解释

### 3.1 证明前

对长证明先给路线图：

- 障碍是什么；
- 将构造什么中间对象；
- 哪一步产生核心推进或关键约束；
- 最后如何闭合。

路线图不能预先使用尚未定义的术语；必要时链接第零章。

### 3.2 证明后

非平凡定理后给结构注记，说明：

- 定理真正说了什么；
- 哪些假设负责哪些结论；
- 证明的核心机制；
- 哪一步最不可替代；
- 后文如何调用。

若定理已经非常简单且证明完全透明，可以省略独立注记，避免机械增框。

## 4. 常见错误检查

### 4.1 定义与假设

- 是否漏了对象范围、可用结构、存在性、有限性或其他必要条件；
- 等价刻画是否在当前类别内才成立；
- 极端、退化或边界情形是否单独处理；
- 是否把只在附加条件下成立的性质当成一般结论；
- 是否把相近但不同层次的对象混为一谈。

### 4.2 约定与一致性

在全书开头列出约定并逐章复核。例如：

- 记号、运算次序和对象之间的对应关系；
- 等价、映射、归一化和标签的定义；
- 同一符号在不同章节的取值范围；
- 引用结论的前提与当前语境。

不要靠“习惯”判断；按定义、公式和最小例子逐项检验。

### 4.3 条件、映射与极限过程

- 带参数或带例外情形的陈述是否需要统一范围或统一选择；
- 相似性质、不同类型的像、闭包或完成等操作是否混用；
- 不同收敛、极限或归一化的定义是否严格区分；
- 变换、限制、延拓或比较时是否核查全部前提。

### 4.4 证明顺序

- 不得循环调用待证结论；
- 不得先用后证且无回链；
- 不得把后文深层输入暗中塞入当前完整证明；
- 练习中的结论若正文依赖，应提升为正文。

### 4.5 量纲、缩放与参数

- 用缩放检验公式量纲；
- 检查常数依赖是否统一；
- 检查“取足够大”能否同时满足有限或无限多个条件；
- 检查方向、逆向操作、对偶构造和临界参数；
- 检查端点、空指标集和分段公式。

## 5. 深层输入模板

```latex
\begin{deepinput}[结果名称]\label{thm:...}
在假设……下，有……
\end{deepinput}

\begin{proofidea}
\begin{enumerate}
  \item 先用……得到……
  \item 核心困难是……；这里调用……
  \item 最后由……推出结论。
\end{enumerate}
\end{proofidea}

\begin{note}
本书后文只使用……。第一遍需要理解……，不要求复现……。
完整证明还需要……，参见……。
\end{note}
```

标题或环境视觉上必须带星号，防止与本书已完整证明的定理混淆。

## 6. 自洽性的诚实边界

可独立学习不要求把全部现代数学从公理重建。合格的分层自洽至少要求：

- 基本对象和符号在书内定义；
- 主线结论的精确形式在书内陈述；
- 每次调用能追溯到正文、前置章或明确深层输入；
- 深层输入的作用和边界可理解；
- 读者不必回查被重制的来源才能知道当前论证在做什么。

若用户要求“完全替代原资料”，优先覆盖原资料的主要概念、命名结果和关键证明；仍无法在合理篇幅内展开的专著级基础，必须在写作合同中向用户说明。
