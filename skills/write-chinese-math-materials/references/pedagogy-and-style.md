## 1. 成品定位

把材料写成读者可以从头连续学习的教材。不要把来源的目录、公式和结论压缩成一份“看起来完整”的提纲。教材应让读者知道：

- 当前问题从哪里来；
- 新对象为何需要定义；
- 定理解决什么困难；
- 证明每个阶段在排除什么障碍；
- 结论怎样连接后文；
- 第一遍究竟要掌握到什么程度。

严谨、完整与通俗、流畅不冲突。“通俗”不等于删除数学细节，“严谨”也不等于省略解释。按语境，既要给精确数学对象，也要用可靠的直观帮助读者建立图像；直观不能替代假设、量词或证明。

## 2. 读者模型与阅读层级

### 2.1 先写读者合同

明确列出可默认掌握的课程与技能，不把“本科基础”“了解某领域”当成无限授权。区分：

- 熟练使用；
- 学过但不熟练；
- 只见过名词；
- 完全未学。

若读者已经学过基础课程，只补当前主线真正调用的接口，不要求从头系统重修整门课。

### 2.2 建议的四种阅读层级

- **必读：** 后文持续调用，需能精确理解并使用主要结论。其中根据实际情况可以要求掌握证明，也可以只要求会核对假设并调用结论。
- **即时补读：** 到指定章节前再读；无需在开篇一次学完。
- **概览：** 第一遍只需了解的内容应能定性说清“是什么、在说什么、为什么大致合理、后文怎样用”，不要求复现技术细节。
- **长期入口：** 给精确对象和阅读地图，为以后深入准备。

在章首或全书导读中标出层级。整节若只需概览，应在行文上优先呈现动机、逻辑、思路、直观与联系。

### 2.3 第零章与附录

第零章放“最低充分前置”：正文会实质调用，但逐次插入会打断主线的前置接口。按使用时机再分为：

- 第一章前必读；
- 到第若干章前即时补读；
- 仅在某个证明中查阅。

附录只放第一遍正文不必顺序阅读的技术证明、查询表、扩展专题、完整题解和参考资料。正文需要附录内容时在首次调用处链接到具体定义或讲解。

## 3. 章节和小节结构

### 3.1 章首

建议依次给出：

1. 学习目标与完成标准；
2. 前置回顾及链接；
3. 阅读层级与可跳过部分；
4. 核心问题和研究动机；
5. 本章在全书依赖图中的位置。

若章节对应一周，再给预计时间、分日建议与周验收。

### 3.2 正文

优先采用：

1. 动机和模型问题；
2. 定义；
3. 最小例子与反例；
4. 关键引理；
5. 主定理；
6. 分步骤证明；
7. 结构注记；
8. 后续接口。

不要为了形式整齐机械重复这一顺序；但不能省掉读者理解所需的逻辑桥梁。

### 3.3 章末

建议列出：

- 本章结论清单；
- 依赖和去向；
- 常见误区；
- 精选习题；
- 阶段验收；
- 指向题解、正文知识点和下一章的链接。

## 4. 定义、例子与注记

<a id="definition-basics"></a>

### 4.1 定义

正式 `definition` 环境和正文首次引入的概念都按定义处理。被定义的核心术语加粗。映射的定义域与陪域、变量所属集合和符号作用域须清楚，首次出现及作用域改变时尤其核对（定理、证明、例子和注记同样适用）。不得用未定义的对象解释另一个未定义的对象；需要的辅助概念先给最低充分定义，已有内容则回链到具体位置。复杂定义后至少回答一个问题：

- 为什么采用这些条件；
- 各条件分别排除什么坏情形；
- 与熟悉对象怎样对应；
- 哪个例子最能显示本质；
- 后文在哪儿使用。

真正显然的记号约定、直接命名或一眼可懂的标准对象可不另加注记。不一定全部要求独立注记环境，但当更适合用独立注记环境时，注记需要用楷体（也适用于其他注记）。实际比较相近对象时，直接给出带适用条件和清楚类型的关系，不能只分别重复定义。直观和比喻也不得混淆对象类型。

### 4.2 例子与反例

需要掌握的主线抽象概念用最低可计算模型帮助理解，已有合适模型可以复用，不要求每个符号另配例子。反例、边界例和研究中的真实例子按实际教学需要增加，不统一要求每个概念配置齐套。核对例子确实满足假设，反例确实揭示所说边界。

### 4.3 实质性注记

合格注记应能：对非平凡、抽象或条件复杂的结果帮助读者理解陈述整体在说什么，对需使用或记忆的公式和判据给出整体印象并说明各项如何表达这一事实，对较难抓住重点的证明说明其核心步骤/思想；不给证明时给准确的直觉和合理性说明，不能用高度压缩的推导冒充直观；高度非平凡的结果可以诚实说明严格理由依赖核心技术，但仍须说清结论含义；多条件结果先说明学习责任，再解释条件大致带来的好处或排除的情形；若严格解释会引入新课程，只作准确的定性说明；无需背诵条件时明说，实际调用时仍需回来核对。

仅复述公式、说“这很重要”或换一种说法重复定理不算解释。不要机械添加“直观理解：”或“注意：”等前缀；直接写有信息量的内容。

## 5. 中文表达与术语

- 使用严谨、平实、准确、通俗易懂的中文；避免炫技、花哨、晦涩或翻译腔。
- 数学家姓名保留英文拼写。
- 中文术语在第一次出现时标注英文原词，之后使用统一中文译名。
- 维护术语表和弃用译法表，记录每个术语的统一写法和选择理由，但不得让读者在读正文时被迫要专门去查术语表/字母表。
- 不把本地文件代号、作者内部编号或临时缩写变成定理名、方法名或知识点名称。若使用代号指代了常用的资料本体，则在前言给出代号—完整资料名（非文件名）唯一映射。
- 数学表达式与资料代号分开判断；数学表达式本身不应因为外形类似资料代号而被清理误删。
- 英文术语保留时说明原因，例如尚无稳定译法或中文读者通常直接使用。
- 名词、术语、短语、符号、约定等，一定要符合人类学术惯例，切勿自造变量名式伪术语，写英文时除非相应表达确符合惯例，否则不滥用串状名词性短语和连字符；
- 逐句检查主语、动作、指代、逻辑和信息顺序，拆开同时承担定义、例外、证明和用途的长句。
- 慎用“不是X，而是Y”：X须是上下文自然出现的解释或真实易错点，不凭空造靶。
- 解释知识用标准数学术语或真正易懂、对应清楚的比喻，不得自造非标准的类术语。“黑箱、接口、图景、技术包、桥梁、骨架、枢纽”等指代明确且有助理解，或只是无歧义的无害修饰时可以保留，但这些词不得代替数学陈述。
- 正文只面对当前版本读者，不解释已经删除的旧措辞，不作跨版本追责。命题改动后同步检查注记、例子、题解和引用。
- **特别文法约束**：① 避免孤句、孤立动作成句、祈使句指导语气不完整等问题；② 避免断句与气口不自然、停顿突兀、意思尚未完整就结束等；③ 必要的虚词、过渡词、辅助词不能过多省略；④ 避免相邻句连接不顺、上下文不连贯、过渡不顺畅、前后句段逻辑关系弱等问题。
- **特别指导思想**：① 降低人类读者在阅读时的 perplexity，尽量用人类常用而不是 Coding Agent 常用的语言词句组合，也不能让行文工程化。② 提高人类读者的 cache hit 率。③ 照顾到 context window length 较弱的人类读者，避免读者需要带着疑问一次性读一大段之后回过头来才能看懂。

对于不明确知道如何翻译的术语，切勿强行翻译，应当联网查阅是否有公允译法，如无法联网或尚无统一公允译法，应保留原术语。用数学家名字命名的术语不要硬译（例如：Abel 群、Jacobian/Jacobi 行列式，不要：阿贝尔群）。

## 6. 卡点审计

逐节模拟目标读者阅读，记录每一个可能迫使读者外问的卡点：

- 新术语未定义；
- 使用了后文才出现的对象；
- “显然”实际需要多步；
- 公式方向或约定突然变化；
- 只给抽象结论，没有模型；
- 注记没有解释真正困难；
- 未展开证明的结果没有告诉读者第一遍该掌握什么。

每个卡点选择一种处置：

1. 在正文即时补足；
2. 加入第零章并回链；
3. 标成概览，或带星号且明确阅读与证明边界的结果；
4. 增加例子、反例、证明路线或注记；
5. 若确实非主线，移到附录。

验收标准不是“读者理论上能查到”，而是“目标读者无需频繁借助外部问答即可顺畅推进”。

### 两个阅读障碍案例

以下反馈是实际案例，只用于辨认同类问题；编号和具体数学对象不成为其他教材的必备内容。

> “把 a 指数化为一个全测地平坦子空间。取极大交换子空间”，什么叫指数化、全测地、平坦空间、极大交换子空间？

一句话中有多个未解释的对象。按学习责任补足必要定义或给定性说明，不能再用更深的陌生术语解释它们。

> 定义0.5中未明确指出 dF 是从什么到什么的映射，未指出 h 位于切空间中。全书所有定义的映射必须明确指出是从哪里到哪里；数学符号、记号等的作用域也必须清晰可辨识。

定义环境不能代替对象类型与作用域的说明；先让读者知道符号指什么，再补直观。

## 7. 取舍原则

每项增补先判断后文是否需要、读者需学到哪一层、能否用已有知识、最小模型、短计算或精确回链解决。为解释A引入更深B却没有关闭A的困难，又留下B的缺口，则增补无效。按既定责任就地解释、定向补读、明确只作概览、移附录或删除；不得自行改变已批准的学习与证明责任。达到所需结论即止。优先删同义复述、过度重复和无用旁支，保留有效动机、过渡、证明路线与关键细节；不设统一扩写或压缩比例，也不以缩字号控制页数。
