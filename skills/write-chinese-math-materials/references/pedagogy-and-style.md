# 教学写作与中文表达规范

## 目录

1. 成品定位

## 1. 成品定位

把材料写成读者可以从头连续学习的教材。不要把来源的目录、公式和结论压缩成一份“看起来完整”的提纲。教材应让读者知道：

- 当前问题从哪里来；
- 新对象为何需要定义；
- 定理解决什么困难；
- 证明每个阶段在排除什么障碍；
- 结论怎样连接后文；
- 第一遍究竟要掌握到什么程度。

“通俗”不等于删除数学细节，“严谨”也不等于省略解释。先给精确数学对象，再用可靠的直观帮助读者建立图像；直观不能替代假设、量词或证明。

## 2. 读者模型与阅读层级

### 2.1 先写读者合同

明确列出可默认掌握的课程与技能，不把“本科基础”“了解某领域”当成无限授权。区分：

- 熟练使用；
- 学过但不熟练；
- 只见过名词；
- 完全未学。

若读者已经学过基础课程，只补当前主线真正调用的接口，不要求从头系统重修整门课。

### 2.2 建议的四种阅读层级

- **必读：** 后文持续调用，需能复述定义并使用主要结论。
- **即时补读：** 到指定章节前再读；无需在开篇一次学完。
- **概览：** 第一遍掌握问题、结论、证明机制和联系，不要求复现技术细节。
- **长期入口：** 给精确对象和阅读地图，为以后深入准备。

在章首或全书导读中标出层级。整节若只需概览，应在行文上优先呈现动机、逻辑、思路、直观与联系。

### 2.3 第零章与附录

第零章放“最低充分前置”：正文会实质调用，但逐次插入会打断主线的前置接口。按使用时机再分为：

- 第一章前必读；
- 到第若干章前即时补读；
- 仅在某个证明中查阅。

附录只放第一遍正文不必顺序阅读的技术证明、查询表、扩展专题、完整题解和参考资料。正文需要附录内容时在首次调用处链接过去。

## 3. 章节和小节结构

### 3.1 章首

建议依次给出：

1. 学习目标与完成标准；
2. 前置回顾及链接；
3. 阅读层级与可跳过部分；
4. 核心问题和研究动机；
5. 本章在全书依赖图中的位置。

若章节对应一周，再给预计时间、分日建议与周验收。

### 3.2 正文

优先采用：

1. 动机和模型问题；
2. 定义；
3. 最小例子与反例；
4. 关键引理；
5. 主定理；
6. 分步骤证明；
7. 结构注记；
8. 后续接口。

不要为了形式整齐机械重复这一顺序；但不能省掉读者理解所需的逻辑桥梁。

### 3.3 章末

建议列出：

- 本章结论清单；
- 依赖和去向；
- 常见误区；
- 精选习题；
- 阶段验收；
- 指向题解、正文知识点和下一章的链接。

## 4. 定义、例子与注记

### 4.1 定义

正式 `definition` 环境和正文首次引入的概念都按定义处理。复杂定义后至少回答一个问题：

- 为什么采用这些条件；
- 各条件分别排除什么坏情形；
- 与熟悉对象怎样对应；
- 哪个例子最能显示本质；
- 后文在哪儿使用。

真正显然的记号约定、直接命名或一眼可懂的标准对象可不另加注记。

### 4.2 例子与反例

至少为主线抽象概念配置：

- 一个最小可计算例子；
- 一个说明条件不可删的反例或边界例；
- 必要时一个后文研究对象中的真实例子。

检查例子是否真的满足全部假设。错误反例比没有反例更具误导性。

### 4.3 实质性注记

合格注记应回答下列问题之一：

- 结论在当前问题中的结构或直观含义是什么；
- 证明的真正核心是哪一步；
- 条件为何不可删除；
- 一般化需要增加什么工具；
- 结论与前后章节如何连接。

仅复述公式、说“这很重要”或换一种说法重复定理不算解释。不要机械添加“直观理解：”或“注意：”等前缀；直接写有信息量的内容。

## 5. 中文表达与术语

- 使用严谨、平实、准确、通俗易懂的中文；避免炫技、花哨、晦涩或翻译腔。
- 数学家姓名保留英文拼写。
- 中文术语第一次出现时标注英文原词，之后使用统一中文译名。
- 维护术语表和弃用译法表，记录每个术语的统一写法和选择理由。
- 不把本地文件代号、作者内部编号或临时缩写变成定理名、方法名或知识点名称。本地代号只能指向资料本体；在前言给出代号—完整书目唯一映射。
- 数学表达式与资料代号分开判断；数学表达式本身不应因为外形类似资料代号而被清理误删。
- 英文术语保留时说明原因，例如尚无稳定译法或中文读者通常直接使用。

对于不明确知道如何翻译的术语，切勿强行翻译，应当联网查阅是否有公允译法，如无法联网或尚无统一公允译法，应保留原术语。用数学家名字命名的术语不要硬译（例如：Abel 群、Jacobian/Jacobi 行列式，不要：阿贝尔群）。

## 6. 卡点审计

逐节模拟目标读者阅读，记录每一个可能迫使读者外问的卡点：

- 新术语未定义；
- 使用了后文才出现的对象；
- “显然”实际需要多步；
- 公式方向或约定突然变化；
- 只给抽象结论，没有模型；
- 注记没有解释真正困难；
- 深层输入没有告诉读者第一遍该掌握什么。

每个卡点选择一种处置：

1. 在正文即时补足；
2. 加入第零章并回链；
3. 标成概览或带星号深层输入；
4. 增加例子、反例、证明路线或注记；
5. 若确实非主线，移到附录。

验收标准不是“读者理论上能查到”，而是“目标读者无需频繁借助外部问答即可顺畅推进”。

## 7. 取舍原则

保留：

- 后文依赖的定义和结论；
- 命名主定理；
- 关键证明机制；
- 能揭示本质的例子、反例和练习；
- 研究主线所需的技术接口。

合并或删除：

- 重复证明和同质例子；
- 与目标主题弱相关的历史旁支；
- 低收益的分类计算；
- 只增加篇幅、不增加理解的文字；
- 原书中大量重复训练。

任何删改都先检查依赖矩阵，不能因“简洁”删除后文实际调用的输入。
